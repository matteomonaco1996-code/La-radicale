# Tenuta La Radicale — Guida per gli ospiti

Sito per gli ospiti della tenuta, in italiano e inglese. Ogni modifica caricata sul ramo `main`
viene pubblicata in automatico su GitHub Pages.

- `index.html`: tutta la guida. Testi, orari, telefoni e link sono negli elenchi all'inizio
  dello `<script>` (`EAT`, `BARS`, `SHOPS`, `SOS`, ...).
- `img/`: foto della tenuta.
- `sw.js`: copia locale per consultare la guida anche con poca rete. Dopo una modifica ai
  contenuti, cambiare `la-radicale-v1` in `v2`, `v3`, ... per forzare l'aggiornamento.
